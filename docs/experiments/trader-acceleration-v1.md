# Wallet500 Trader Acceleration V1

Status: RESEARCH ONLY
Production portfolio impact: NONE
Lookahead policy: FORBIDDEN
Pair identity: EXACT LOCKED PAIR ONLY
Verified Tradable liquidity rule: >= $50,000 (UNCHANGED)

## Purpose
Measure whether a move is being adopted by a growing population of unique traders rather than being generated by repeated transactions from a small wallet set.

## Required observations
For each exact pair, preserve timestamped observations for 5m / 15m / 30m / 60m windows when the underlying source can verify unique wallet identities:
- unique_buyers
- unique_sellers
- unique_traders
- new_unique_buyers
- new_unique_sellers
- net_new_traders
- unique_buyer_growth_pct
- unique_seller_growth_pct
- unique_trader_growth_pct
- repeat_trade_ratio
- tx_per_unique_trader
- buyer_to_seller_unique_ratio
- cluster_adjusted_unique_buyers (only when cluster evidence is verified)
- source / source_timestamp / verification_status

## Truth rules
1. Never substitute transaction counts for unique trader counts.
2. Missing wallet-level evidence remains null / UNVERIFIED; never infer unique traders from buys/sells.
3. All measurements belong to chain + token + EXACT PAIR. Never merge pools.
4. No historical observation may be rewritten after later outcomes are known.
5. Cluster-adjusted values remain null unless wallet/cluster evidence is independently verified.
6. This metric cannot promote a token to Verified Tradable or change portfolio actions in V1.
7. Liquidity >= $50K and all existing security/survival gates remain mandatory for Verified Tradable.

## Research hypotheses
Compare future outcomes against:
- trader acceleration with rising/stable liquidity
- trader acceleration with falling liquidity
- transaction acceleration without unique-trader acceleration
- unique-buyer acceleration vs unique-seller acceleration
- broad independent-wallet adoption vs concentrated/clustered adoption

Primary question: does broad unique-trader acceleration improve post-T0 survival and continuation after controlling for liquidity, volume, price impulse and manipulation risk?
