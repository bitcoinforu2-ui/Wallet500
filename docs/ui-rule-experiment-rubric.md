# Wallet500 UI Rule — Experiment Rubric

Every public Wallet500 dashboard must expose the shared experiment rubric at the top of the page.

Rules:
- Every active experiment/lab with a public data view must have a direct link in the rubric.
- Nested experiments may link to an anchored section in their parent dashboard.
- Research-only experiments must remain clearly labeled by their own truth contracts; navigation visibility never changes production eligibility.
- The rubric is built into every public page by the Pages deployment workflow so new dashboards cannot silently omit it.
- Mobile layout must remain horizontally scrollable instead of hiding experiment links.

Current rubric targets: Project Status, Revival, Absorption / Pre-Move, Paid Attention, Decision Lab, KOL Forward, $1 Performance, 7/30/90 Research, Hybrid, CYBERLEEK, External-only, Live, Control Center.
